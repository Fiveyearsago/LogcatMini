The official macOS arm64 and x86_64 static executables are combined using
Apple lipo and locally signed, with no source-code modifications. The Android
server is unchanged. No bundled adb is used: Logcat Mini supplies its chosen ADB.
Reproduce the runtime using scripts/prepare-recording-runtime.sh in the project.
