# Mac 自动测试公开分支验证（2026-10-26）

`feature/mac-automation` 在公开 `main` 基础上增加自动化工作区，包含主线的日志、投屏、设备信息、媒体、本地项目构建、请求调试和发布时间功能。

## 实现范围

- 完整 APK 元数据检查、保留数据覆盖安装、用例导入与编辑、页面操作、日志断言、失败截图、历史复测及 Markdown/附件导出。
- 动态页面的控件树读取回退、`belowText` 关系定位与唯一性检查、新版 aapt2 的最低 SDK 解析。
- 自动化与日志页面切换；退出时协调测试、媒体、构建和投屏的停止与保存。
- 真实业务用例替换为虚构包名、控件和日志约定的合成示例。测试设备通过环境变量显式指定，没有预设真实序列号。

## 本次验证

- `swift test`：225 项，0 失败，其中 9 项需显式授权设备的集成测试跳过。包括两个公开 JSON 示例的严格导入和配置校验。
- `bash scripts/build-automation-preview.sh` 与预览版严格签名校验通过；离线 Release 演示 APK 构建与签名校验通过，未安装到手机。
- 主线此前完成 205 项测试，0 失败，7 项设备测试跳过；Release 构建与签名检查通过。
- 本次公开同步未操作连接的手机，不代表真实业务全流程、任意广告素材、Intel Mac 或 Windows 实机验收。
- 继续保留公开版自行配置解密服务和 RSA 密钥的方式，日志夹具为合成数据。私有历史、内部默认接口、默认业务密钥、原始运行记录和设备信息没有导入。

## 后续待办

| 优先级 | 内容 | 验收方向 |
| --- | --- | --- |
| P1 | 多实例设备互斥、取消与子进程清理 | 同一设备不被多个实例抢占，停止或断线后没有晚到操作 |
| P1 | 结构化日志断言 | 支持关联事件的数量、顺序、数值和时间窗口，报告展示依据 |
| P1 | 业务流程的真实结果核验 | 区分界面动作成功、客户端回调和服务端业务完成；记录人工接管与阻塞 |
