Logcat Mini 0.2.0 — Windows x64 预览版

目标：Windows 10/11，Intel/AMD 64 位电脑。
已验证共享代码、Mac 预览界面及真实 Android 连接；Windows 实机尚未验收。

安装
1. 右键 ZIP，选择“全部解压”，然后双击文件夹中的 LogcatMini.exe。
   保留整个文件夹，不要只复制 EXE，不要在压缩包内运行。
   已自带 .NET 运行环境，无需安装 .NET 或 Android Studio。
2. 软件会尝试自动找到本机 Android SDK 中的 adb.exe。
   如果没有，请下载并解压 Google 官方 Windows Platform-Tools：
   https://developer.android.com/tools/releases/platform-tools
   点击左侧“设置”中的“更换 ADB”，选择 platform-tools 中的 adb.exe。
   也可将完整 platform-tools 文件夹放到 LogcatMini.exe 旁边。
3. 手机开启“开发者选项 / USB 调试”，连接数据线并允许手机上的调试授权。
   Windows 未识别设备时，按厂商说明安装官方 USB 驱动：
   https://developer.android.com/studio/run/oem-usb
4. 点击“↻”刷新，选择设备、应用，再点击“开始采集”。

功能
- 星标收藏包名，收藏置顶，自动读取真实应用名称及图标。
- 七套主题，字号 10–26 pt；主题、字号、收藏、列和侧栏宽度会保存。
- 拖动侧栏右边缘调整宽度，拖动详情上边缘调整高度。
- 等级、时间、Tag、PID 使用等级颜色；消息和详情保留语法颜色。
- 内容过滤及 Tag 过滤均支持用 | 分隔多个关键词，任一关键词命中即可；
  内容、Tag、等级三个条件同时生效。“正则”选项将内容框按正则匹配。
- 过滤框右侧“历史 / 收藏”可恢复整组关键词、Tag、等级和正则开关。
  输入后按回车或离开过滤区域保存，最近 30 条；点击 ☆ 收藏，★ 再次点击取消。
  收藏置顶并长期保留，清空历史不会删除收藏；下次启动不会自动套用旧条件。
- 设置中的“显示列”可隐藏 PID 等列，至少保留一列。
- 日志区域支持横向滑动，普通鼠标使用 Shift+滚轮。
  也可拖动底部横向滚动条，或选中后按左右方向键。表头和所有行、所有列一起移动。
- 点击日志查看详情，“格式化日志”位于复制左侧；JSON 支持节点展开/折叠，
  Map 和键值日志支持分行排版。格式化文本可跨行选择；Ctrl+C 复制选区，
  工具栏“复制”复制完整格式化内容（包括折叠部分），原始模式则复制源记录。
- 列表和详情均可查找，高亮并定位；查找不会改变过滤结果。
- 日志全屏隐藏菜单并保留全部过滤控件，详情全屏占满窗口；按钮及 Esc 可恢复。
- 同来源、连续、完整的 result_part=1/N ... result= 分段自动合并为一条。
  列表、详情、复制、导出均使用完整 result= 数据；缺段/不明确时保留原样。
- 日志无固定条数上限，只在本次会话内存保留，退出后清空，不保存历史文件。
  长时间大量采集会增加内存占用，可导出后清空。
- 清空视图不清空手机日志，停止采集不关闭系统 ADB 服务。
- Ctrl+点击多选，Shift+点击连续选择，Ctrl+A 全选当前列表或详情文本。
- 设备切换保留每台设备本次会话的日志和包名；清空只影响当前设备。
- 截图、录屏第一次选择文件夹后自动保存，设置中可分别更换文件夹。
  录屏最长 3 分钟、无音频，绑定开始录制时的设备。切换设备不改变录屏目标。
  停止或退出客户端时保存；失败可换目录重试，“取消重试”保留临时文件。
- “截图与录屏历史”可搜索、按类型筛选、预览图片、播放录屏和打开所在文件夹。
  文件被移走后历史仍保留并提示缺失。历史跨启动恢复，实时日志不跨启动保存。
- Windows 内嵌视频播放使用系统媒体组件；预览不可用时可“打开 / 播放”使用系统播放器。
- 工具栏图标使用矢量绘制，保持与 Mac 相同的含义与风格，不依赖图标字体。

快捷键
Ctrl+,         打开设置
Ctrl+F         显示/隐藏当前列表或详情的查找框
Ctrl+G         下一个匹配
Ctrl+Shift+G   上一个匹配
Enter/Shift+Enter  查找框内跳到下一个/上一个匹配
Ctrl+加号/减号 放大/缩小日志字体
Ctrl+0         恢复 14 pt
Ctrl+Shift+F   日志全屏/恢复菜单
Ctrl+Alt+F     日志详情全屏/恢复
Esc            先关闭当前查找框，再退出全屏
Ctrl+R         开始/停止采集
Ctrl+P         暂停/恢复显示（暂停期间继续采集）
Ctrl+K         清空视图
Ctrl+Shift+S   导出当前过滤结果
Ctrl+C         复制选中日志或当前详情

设置保存到 %LOCALAPPDATA%\LogcatMiniWindows，保存设置、应用元数据和媒体历史索引，无实时日志历史。
更新时解压到新文件夹即可，原设置仍可读取。

问题排查
- 本预览版尚未进行 Windows 代码签名，可能出现“未知发布者”提示。
  如被组织策略阻止，请交管理员确认，无需关闭系统安全防护。
- unauthorized：请在手机允许 USB 调试授权。
- 没有日志：确认应用正在输出新日志，并检查过滤条件；点击全部应用进行排查。
- 无法读取图标时，包名收藏和采集仍可使用。
- 录屏组件缺失时，在设置中选择官方 scrcpy 文件夹内的 scrcpy.exe，保留同目录依赖。
- Windows 7/8 和 32 位系统不在本版目标范围内。
